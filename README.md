# Event.Book

A modern event management system designed to streamline the process of planning, booking, and managing events of all sizes. Event.Book offers an intuitive platform for organizers, attendees, and vendors to collaborate seamlessly.

---

## 🚀 Features

- **Event Creation & Management:** Easily create, update, and manage events.
- **Booking System:** Secure and flexible booking for attendees.
- **User Authentication:** Secure sign-up, login, and profile management.
- **Event Calendar:** Visualize upcoming events in an interactive calendar.
- **Notifications:** Stay updated with real-time email or in-app notifications.
- **Admin Dashboard:** Powerful tools for event organizers and admins.
- **Mobile Responsive:** Accessible from any device.

---

## 🛠 Tech Stack

- **Frontend:** [Next.js 14](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Backend:** [Node.js](https://nodejs.org/)
- **Database:** [MongoDB](https://www.mongodb.com/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)

## ⚡️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (vXX.XX+)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- (Add any other prerequisites)

### Installation

```bash
# Clone the repository
git clone https://github.com/Prabharsha/Event.Book.git
cd Event.Book

# Install dependencies
npm install

# Setup environment variables
cp .env.example .env
# Edit .env with your configuration

# Start the development server
npm run dev
```

---

## 💡 Usage

- Access the app at `http://localhost:3000` (or your configured port).
- Register an account and start creating or booking events.
